## Головне рішення

Усі факти живуть у підготовлених базах, а модель відповідає лише за мову. Системний промпт
прямо забороняє наводити формули з пам'яті: якщо інструмент нічого не знайшов, бот каже
про це чесно.

Причина продуктова. Правильна формула з бази і вигадана формула з пам'яті моделі виглядають
для студента абсолютно однаково, бо він звернувся саме тому, що не знає теми. Якщо система
інколи вигадує, довіряти не можна жодній відповіді.

## Що змінено в шаблоні варіанта

Архітектура збережена повністю, переписана лише логіка всередині інструментів. Кожна правка
виправляє помилку, яка ламала саме ті приклади, що наведені в docstring шаблону як зразкові:

| Що було | Що ламалося | Як виправлено |
|---|---|---|
| Пошук формули збігом підрядка | «формула кінетичн**ої енергії**» не знаходила «кінетичн**а енергія**» | ранжування за схожістю з обрізанням слів до кореня |
| Числа планувальника за порядком | «7 днів щоб вивчити 20 тем» читалося як 7 тем за 20 днів | числа шукаються за ключовими словами «тем», «днів», «годин» |
| Одиниця конвертації за першим збігом | «скільки фаренгейтів у 37 цельсія» не визначало напрямок | вихідною вважається одиниця, найближча до числа |
| Формат `%g` для результату | 506625 показувалося як `5.066e+05` | великі числа виводяться повністю, з розділювачем розрядів |

## Що знайшло власне ревʼю

Після шаблону я прогнав код через два незалежні аудити та власні тести. Знайшлося ще
кілька помилок, і найнебезпечніші були саме в тому, проти чого побудований продукт:
**впевнена неправильна відповідь**.

| Знахідка | Як проявлялася | Виправлення |
|---|---|---|
| Одностороння міра схожості | «закон збереження енергії» → **ЗАКОН ОМА** з оцінкою 1.0 | двостороння міра F2, повнота покриття запиту важить більше |
| Підрядковий збіг як «ідеальний» | «швидкість світла» → формула середньої швидкості | гілку прибрано, міра й так дає 1.0 на повному збігу |
| Напрямок конвертації за відстанню | «переведи в м/с 100 км/год» → `100 м/с = 360 км/год` | вихідна одиниця це перша ПІСЛЯ числа |
| Пошук одиниць без меж слова | «за шкалою Цельсія» давало фантомну одиницю «кал» | пошук по межах слова через regex |
| Втрата значущих цифр | `0 C = 273.1 K` замість 273.15 | формат з 6 значущими цифрами |
| Колізія стемів у таблиці елементів | «гідроксид натрію» → **Гідроген** | явний словник назв замість обрізання до кореня |
| Округлення вниз у плані | 10 тем на 4 дні: теми 9 і 10 зникали | `math.ceil` замість `round` |
| Подвійне округлення | «Потрібно 8, доступно 25, резерв 18» (25−8=17) | округлення один раз, різниця за округленими |
| Автотести зараховували збій як успіх | при мертвому ключі тести проходили | окремий вердикт 💥 |

Кожна закрита регресійним тестом. Разом **46 перевірок інструментів**, усі проходять.
